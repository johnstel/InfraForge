## Learnings

### Session: 2026-05-14 — Azure Tenant Deployment Planning

**Context:** John requested deployment plan for InfraForge to his Azure tenant, plus guidance for Electric Energy customers (Consumers Energy, etc.).

**Findings:**

1. **Minimal infrastructure baseline:** InfraForge requires only Azure SQL (Basic tier, ~$5/mo) + App Service (B1, ~$8/mo). No HA, no redundancy unless customer explicitly requests it.

2. **Setup automation exists:** `scripts/setup.ps1` handles 90% of provisioning (resource group, SQL, Entra ID app reg, RBAC, Fabric workspace). Interactive prompts, auto-rollback on failure, comprehensive error handling and retry logic.

3. **Managed identity + SQL firewall:** Auto-detects public IP on startup, updates SQL firewall rule, retries with bounded backoff. Eliminates hardcoded IP allow-lists, improves DX.

4. **Configuration is env-var based:** `.env` file generated by setup script. Never committed to git. No config files to sync. Supports local dev, CI/CD, and App Service settings seamlessly.

5. **GitHub Actions integration:** Customers can publish generated infrastructure to repos; setup script can auto-extract `gh` CLI token. Optional but reduces friction.

6. **Fabric IQ optional:** Analytics integration exists but skippable (`-SkipFabric`). Customers without Fabric capacity can still deploy InfraForge.

7. **Work IQ optional:** Microsoft Work IQ MCP (org knowledge search) is integrated but can be disabled if Node.js 18+ isn't available.

**Key Decision:** Recommend **Phase 3 (App Service deployment)** for John first. Test in non-prod subscription, document any gaps, then create customer kit.

**Blockers for Customers:**
- Second Entra ID app registration required (InfraForge ships single app reg)
- GitHub org setup required (assume customer has one or create personal account)
- Fabric capacity optional but required for analytics (post-MVP: design doc recommends Fabric F2 ~$300/mo)
- Data residency compliance not automatically tagged; customer must document requirements

**Cost Model:** $156/year baseline (SQL + App Service) + $0–$3,600/year (if Fabric). Customer-generated infrastructure costs vary by template.

**Deliverable:** Comprehensive Azure Tenant Deployment Plan document created at `.squad/decisions/inbox/kaylee-azure-deployment-plan.md`. Includes resource architecture, tenant prerequisites, env vars, deployment sequence, checklist for customers, cost estimate, and post-deployment playbook.

**Recommended Next Step:** John tests Phase 3 deployment to App Service in non-prod subscription, validates Entra ID + Fabric integration, then packages into customer onboarding kit.
