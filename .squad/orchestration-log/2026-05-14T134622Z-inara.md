## Key Outputs

- **Positioning Statement**: InfraForge is governance-first, self-service infrastructure platform
  - For app teams: Natural language requests, no IaC, no waiting, cost visibility, one-click deployment
  - For platform teams: Approve once, enforce always, cost tracking by cost center, audit trails
  
- **Utility Value Proposition**: Three critical pain points solved:
  1. **Governance & Compliance Risk** — Manual requests are audit nightmares
  2. **Cost Attribution Failure** — Cloud costs buried; impossible to chargeback
  3. **Self-Service Bottleneck** — IT overwhelmed; app teams waiting weeks
  
- **Four-Pillar Strategy for Utilities**:
  1. Identity-Driven Compliance (FERC/NERC requires responsible party + change tracking)
  2. Cost Governance & Chargeback (estimates shown, automatic departmental attribution)
  3. Policy-as-Code Enforcement (approved services, SKUs, regions; all auditable)
  4. Auditability at Every Step (governance review → generation → cost → deployment → outcome logged)

- **Utility-Specific Demo Scenario**: SCADA data ingestion use case
  - Natural language request with cost center code and budget
  - Governance checks (approved service, user role, cost center, budget limits)
  - Bicep generation with prod-grade SQL (Standard tier, RBAC, managed identity)
  - Cost estimate ($450/month) vs. budget ($500/month)
  - ARM What-If preview before deployment
  - Deployment with progress streaming and audit trail

- **Deployment Model**: Deploy-in-Your-Tenant (not SaaS)
  - Your Azure subscription, your SQL, your App Service
  - You create Entra ID app registration
  - Baseline cost: ~$13/month
